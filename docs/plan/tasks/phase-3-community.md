# Phase 3 · MVP-3 (community)

[← Plan index](../README.md) · Release: MVP-3 (required before public launch) · Schema sketch: [ERD MVP-3](../erd/mvp-3.md)

**Goal:** opt-in sharing between couples, with joint approval and working moderation.

This covers scope slices 3–5. **Write the design doc first**: none of this has requirements yet.

---

- [ ] **P3-1 · Community spec** · M — What's shareable (a revealed answer pair? a written reflection?), the couple's public identity (handle, no names or photos), age and consent rules, and dual liability ([Q12](../03-product-decisions.md#q12)).
- [ ] **P3-2 · Opt-in community profile** · M — Both partners must opt in.
- [ ] **P3-3 · Joint-approval publishing** · L — Draft → both approve → published. Any edit resets approvals, and either partner can withdraw at any time.
- [ ] **P3-4 · Reporting** · M — Report a post or couple with preset reasons.
- [ ] **P3-5 · Moderation console + enforcement** · L — Roles, a queue, actions (hide, warn, suspend couple), an audit trail and appeals copy. Suspension blocks publishing.
- [ ] **P3-6 · Stronger identity checks before public launch** · ? — Scope says this gets designed later.
